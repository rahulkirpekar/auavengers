List(I)	Features:-
-----------------

	1. Stores values in Insertion order.
	2. Allows Duplicate Values.
	3. can access by Index
	4. can contain null values.

ArrayList Features:-
-------------------

	1. Stores values in Insertion order.(Ordered Collection)
	2. Allows Duplicate Values.
	3. can access by Index
	4. can contain null values.
	5. Dynamic Resizing
	6. Fast Read Operations 
	7. Non-Synchronized
